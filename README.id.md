# Ahmad Ghumaydi

[← Back to English profile / Kembali ke profil utama](README.md)

Saya **Ahmad Ghumaydi**, pegiat teknologi dari **Sumatera Selatan, Indonesia**, dengan fokus pada jaringan komputer, pengembangan perangkat lunak, dan penelitian terapan. Saya adalah **founder [Xiao Systems](https://xiaosystems.id)** dan menjabat sebagai **Commander [Bina Darma Cyber Army (BDCA)](https://github.com/bidarcyberarmy)** periode 2026/2027.

## Tentang Saya

- Saya tertarik pada **infrastruktur jaringan dan konektivitas nirkabel**, termasuk analisis trafik, identifikasi perangkat, dan pemecahan masalah jaringan.
- Saya membuat prototipe dan solusi perangkat lunak dengan bantuan AI. Fokus saya adalah memahami, menguji, dan mendokumentasikan hasilnya, tanpa mengklaim penguasaan bahasa pemrograman yang belum saya miliki.
- Minat keamanan siber saya kini lebih mengarah ke **keamanan jaringan dan infrastruktur**, bukan CTF.
- Saya ingin mengembangkan penelitian dan eksperimen teknis yang bisa diuji ulang, sekaligus mendorong kolaborasi dan pembelajaran komunitas.

## Jaringan & Infrastruktur

Saya memiliki pengalaman menggunakan **Wireshark**, **Angry IP Scanner**, dan utilitas pemindaian IP, serta bekerja dengan perangkat jaringan dari **MikroTik, Cisco, TP-Link, dan Ruijie**.

Salah satu pekerjaan praktik saya adalah **optimalisasi jaringan Kost Bahagia**, yang melibatkan **12 access point dan 1 router**, dengan perhatian pada cakupan Wi-Fi serta pengalaman perpindahan antar-access point. Repository dan studi kasus teknisnya akan diterbitkan setelah dokumentasi siap.

Bidang yang ingin saya dalami: **jaringan nirkabel · pemantauan jaringan · troubleshooting · otomasi jaringan · keamanan infrastruktur**.

## Pengalaman Profesional

Saya memiliki latar belakang pendidikan **Teknik Jaringan Komputer dan Telekomunikasi** dan pengalaman praktik IT Support di **Universitas Muhammadiyah Palembang (Juni 2023–Januari 2024)**, mencakup instalasi infrastruktur jaringan, pemeliharaan, troubleshooting, serta dukungan perangkat keras dan perangkat lunak.

Saat ini saya menempuh pendidikan **Teknik Informatika di Universitas Bina Darma**.
